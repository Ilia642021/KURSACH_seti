# ВЫБОР ПРОГРАММНОГО ОБЕСПЕЧЕНИЯ И СЕРВИСОВ

Эффективная работа сети предприятия общественного питания обеспечивается набором специализированного ПО и сетевых сервисов.

### 1. Группы пользователей и их задачи
- **Администрация (Cab 1):** Работа с офисными приложениями, ERP-системой, почтовыми сервисами.
- **Кассовая зона (Cab 2):** Фронт-офис системы автоматизации (например, iiko или r-keeper), обработка транзакций.
- **Кухня (Cab 3):** Мониторинг заказов (KDS - Kitchen Display System), взаимодействие с официантами.
- **Склад и логистика (Cab 4):** Учет остатков, работа со сканерами штрих-кодов.
- **Гостевая зона (Cab 5-6):** Доступ к сети Интернет по технологии Wi-Fi с использованием системы авторизации (Captive Portal).

### 2. Используемые сетевые сервисы
В моделируемой сети реализованы следующие типы приложений:
- **HTTP/Web-сервис:** Используется для доступа к внутренним веб-порталам и внешним ресурсам.
- **Базы данных (SQL):** Централизованное хранение данных о продажах, меню и сотрудниках на серверах `hqSrv`.
- **ICMP (Ping):** Используется в процессе моделирования для проверки доступности узлов и измерения времени задержки (RTT).

### 3. Инструментарий моделирования
Для реализации и анализа проекта использованы:
- **OMNeT++ 6.0:** Дискретно-событийный симулятор для проектирования топологии и запуска сценариев.
- **INET Framework:** Библиотека моделей протоколов (TCP/IP stack, OSPF, Ethernet).
- **Python (Matplotlib/Pandas):** Скрипты для автоматизированной обработки результатов симуляции и построения графиков производительности.
