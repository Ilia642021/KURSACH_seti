# ПОДРОБНАЯ СХЕМА СЕТИ (CAMPUS DIAGRAM)

Основой нашей модели в OMNeT++ является иерархическая структура, которая наглядно разделяет сеть на функциональные блоки. На схеме ниже представлено общее расположение всех узлов предприятия.

**(Здесь должен быть Изображение 1: Скриншот топологии из NED-редактора OMNeT++)**

Центральный узел (HQ) выступает в роли «сердца» сети. Здесь расположены два сервера, обеспечивающие работу всей информационной системы, и главный маршрутизатор. Связь с кабинетами осуществляется через центральный коммутатор.

Каждый из шести кабинетов выделен в отдельный логический модуль. Это не только делает схему аккуратной, но и позволяет изолировать внутренние процессы отделов. Внутри каждого такого модуля хосты расположены по принципу «квадрата с точкой в центре» — такая расстановка имитирует реальное размещение рабочих мест в помещении.

Для связи с внешним миром и центральным офисом используются три типа каналов:
- Основной высокоскоростной канал (ppp2).
- Резервный канал (ppp3), который находится в режиме ожидания.
- Выделенная линия для выхода в Интернет.

Такой подход позволяет нам детально изучить, как ведут себя пакеты данных при прохождении через разные сегменты сети.
