# Пояснительная записка к курсовому проекту по сетям
**Вариант 8: Проектирование и моделирование сети предприятия с двумя филиалами**

## 1. Введение
Целью работы является проектирование отказоустойчивой корпоративной сети, обеспечивающей связь между центральным офисом (HQ) и удаленными филиалами, а также доступ к интернет-ресурсам.

## 2. Описание топологии
Сеть состоит из:
- **Центральный офис (HQ)**: 30 рабочих мест, 2 сервера.
- **Филиал 1**: 13 рабочих мест.
- **Филиал 2**: 13 рабочих мест (по условию варианта).
- **Ядро сети**: Маршрутизатор Core, обеспечивающий связь между сайтами и выход в интернет через двух провайдеров (основной и резервный каналы).

## 3. Моделирование в OMNeT++/INET
Для анализа производительности использовалась среда OMNeT++ 6.0.3 с библиотекой INET 4.5.

### 3.1. Результаты измерений (RTT)
| Сценарий | HQ -> Server | Branch -> Server | HQ -> Internet |
| :--- | :---: | :---: | :---: |
| **A: Базовый** | 0.44 мс | 11.10 мс | 41.00 мс |
| **B: Резерв** | 0.44 мс | 11.10 мс | 41.03 мс |
| **C: Отказ** | 0.44 мс | 11.10 мс | 21.03 мс |
| **D: Масштаб** | 0.44 мс | 11.10 мс | 41.20 мс |

### 3.2. Анализ отказоустойчивости (Scenario C)
В ходе моделирования была имитирована авария на основном канале связи с провайдером на 10-й секунде. 
- **Время обнаружения и переключения (OSPF Convergence)**: < 0.001 сек.
- **Результат**: Связь восстановилась практически мгновенно. Использование протокола OSPF позволило перенаправить трафик на резервный канал (ppp3) сразу после обнаружения обрыва физического соединения (interface down). Это подтверждает высокую отказоустойчивость спроектированной сети.

## 4. Теоретические расчеты
Нагрузка на сеть от 43 пользователей и 2 серверов оценивается в **100 Мбит/с** в пиковые часы. 
Выбранные каналы связи:
- Основной: 30 Мбит/с (согласно варианту).
- Резервный: 30 Мбит/с.
- Локальная сеть: 1 Гбит/с.
