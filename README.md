## Архитектура сети
Сеть включает:
- **HQ (Центральный офис)**: 6 подразделений (Администрация, Бухгалтерия, Дирекция, Склад, Кухня, Зал обслуживания). Всего 30 рабочих мест.
- **Серверный сегмент**: 2 локальных сервера приложений/БД.
- **Филиалы**: 2 удаленные точки, подключенные через WAN-линки.
- **Периметр**: Основной и резервный каналы до Интернет-провайдера (ISP).

## Сценарии моделирования
1. **A_Base**: Штатный режим работы через основной канал.
2. **B_ReserveEnabled**: Проверка OSPF-метрик при наличии активного резервного канала.
3. **C_FailurePrimary**: Имитация обрыва основного канала и переключение на резерв.
4. **D_ScaleUp**: Работа сети при увеличении нагрузки (+13 рабочих мест).
