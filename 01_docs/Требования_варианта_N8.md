# Требования к курсовому проекту (вариант N=8)

## 1) Индивидуальные параметры варианта

- Номер варианта: `N=8`.
- Предметная область: информационная система предприятия общественного питания.
- Число филиалов: `2` (так как `N` четное).
- Исследуемая статистика: задержка сети.
- Масштабируемость: добавить `N+5 = 13` рабочих мест.
- Исходные данные варианта:
  - кабинетов: `6`;
  - рабочих мест: `30`;
  - локальных серверов: `2`;
  - канал Internet: `30 Мбит/с`;
  - отдельный анализ влияния резервного канала обязателен.

## 2) Обязательные общие требования методички

- Время моделирования: не менее `10` секунд.
- Должны присутствовать внутренняя и внешняя передача трафика.
- Обязательна отказоустойчивость:
  - однократный обрыв кабеля;
  - отсутствие единой точки отказа.
- Топология должна исключать петли.
- Решение должно учитывать минимизацию затрат.
- Пояснительная записка должна быть оформлена по требованиям методички.

## 3) Чеклист того, что должно быть в финале

- [ ] Рабочая модель сети в OMNeT++/INET с воспроизводимым запуском.
- [ ] Корректная топология для 6 кабинетов, 30 рабочих мест, 2 серверов и 2 филиалов.
- [ ] Набор сценариев экспериментов:
  - [ ] A: базовый режим;
  - [ ] B: влияние резервного канала;
  - [ ] C: отказ (однократный обрыв кабеля);
  - [ ] D: масштабирование до 43 рабочих мест.
- [ ] Графики и таблицы по задержкам, включая сравнение сценариев.
- [ ] Теоретико-расчетная часть и сопоставление с результатами имитации.
- [ ] Спецификация оборудования (минимум 3 варианта на тип) и ведомость стоимости.
- [ ] Полная пояснительная записка по структуре методички.
- [ ] Материалы к защите: презентация и демонстрационный сценарий.
