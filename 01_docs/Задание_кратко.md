# Выжимка задания на курсовой проект (Вариант 8)

## 1. Общие параметры
- **Предметная область:** Информационная система предприятия общественного питания.
- **Цель:** Проектирование и моделирование отказоустойчивой ИВС с анализом задержек.
- **Среда моделирования:** OMNeT++ 6.0 + INET 4.5.

## 2. Технические требования варианта
- **Топология HQ:** 6 функциональных отделов (кабинетов), общее число рабочих мест — 30.
- **Серверный сегмент:** 2 локальных сервера (БД/Приложения).
- **Удаленные сегменты:** 2 филиала, подключенные через WAN.
- **Внешние связи:** Основной канал Интернет (30 Мбит/с) и резервный канал.
- **Параметры трафика:** Размер пакета 800 байт (N*100).
- **Протоколы:** OSPF для обеспечения отказоустойчивости.

## 3. Сценарии моделирования
1. **Сценарий A (Base):** Работа через один основной канал.
2. **Сценарий B (Reserve):** Работа при наличии активного резервного канала (проверка приоритетов маршрутизации).
3. **Сценарий C (Failure):** Имитация обрыва основного канала, проверка автоматического переключения на резерв через OSPF.
4. **Сценарий D (Scale Up):** Масштабирование сети — увеличение числа рабочих мест в HQ на 13 (итого 43 РМ) для оценки стабильности задержек.

## 4. Исследуемая статистика
- Основная метрика: **Задержка сети (End-to-End Delay / RTT)**.
- Дополнительно: Время сходимости OSPF при отказе, пропускная способность каналов.

## 5. Ожидаемые результаты
- Имитационная модель в NED.
- Графики распределения и сравнения задержек по сценариям.
- Теоретический расчет загрузки каналов.
- Технико-экономическое обоснование выбора оборудования.
