# Пояснительная записка по проекту: Курсовая работа (Вариант 8)

Данный документ предназначен для полной передачи контекста проекта «Проектирование и моделирование ИВС предприятия общественного питания» любой нейросети для продолжения работы.

---

## 1. Цель проекта
**Основная задача:** Спроектировать и смоделировать отказоустойчивую информационно-вычислительную сеть (ИВС) для ресторана/кафе (вариант №8).
**Ключевые цели:**
- Обеспечение бесперебойного доступа к 2 внутренним серверам в HQ.
- Организация связи для 6 функциональных зон (кабинетов) по 5 рабочих мест в каждом (всего 30 мест).
- Реализация автоматического переключения на резервный канал связи при отказе основного.
- Исследование влияния параметров трафика (размер пакета 800 байт) на производительность сети.
**Ожидаемый результат:** Полностью работоспособная модель в OMNeT++, набор данных симуляции и готовые разделы пояснительной записки.

---

## 2. Вариант реализации
**Архитектурная концепция:**
- **Иерархическая модель:** Разделение на уровень ядра (Core Router, HQ Switch) и уровень доступа (модули Cabinet).
- **Топология:** «Звезда» внутри кабинетов и иерархическая звезда в центре. Хосты в кабинетах расположены по схеме «4 угла + центр» для визуальной чистоты.
- **Отказоустойчивость:** Динамическая маршрутизация **OSPF** между маршрутизатором ядра (`core`) и провайдером (`isp`) через два канала: основной (`ppp2`, 20ms) и резервный (`ppp3`, 10ms).

**Технический стек:**
- **OMNeT++ 6.0.3:** Среда дискретно-событийного моделирования.
- **INET Framework 4.5:** Библиотека сетевых протоколов (TCP/IP, OSPF, Ethernet).
- **Python (Matplotlib/Pandas):** Анализ векторов задержки (.vec) и скаляров (.sca).
- **Markdown:** Документирование и подготовка отчета.

## 5. Трудности и решения
- **Трудность:** Ошибка "Unknown command-line option --stop-after-event".
  - *Решение:* Заменено на `--sim-time-limit=60s`.
- **Трудность:** Сложность вычисления координат в NED через циклы.
  - *Решение:* Создан вложенный тип `module Cabinet` с фиксированными внутренними координатами.
- **Трудность:** OSPF не успевал сойтись до начала работы приложений.
  - *Решение:* Установлен `startTime = 5s` для всех приложений PingApp.
- **Трудность:** Несоответствие данных в старых отчетах и новых симуляциях.
  - *Решение:* Внедрена система записи логов в `/home/dev/6_sem/KURSACH_seti/03_results`.
